# 📦 日记本数据迁移工具

**版本**: 1.0.0  
**作者**: Etaf Cisky  
**适配**: SillyTavern 1.12.0+  
**用途**: 一次性数据迁移工具

---

## 🎯 功能说明

本工具用于将旧版日记本插件（使用世界书存储）的数据迁移到新版日记本插件（使用 extension_settings 存储）。

### 迁移内容

1. **日记数据** - 从"日记本"世界书迁移所有日记
2. **回收站数据** - 从"回收站"世界书迁移所有回收站条目

---

## 📦 安装说明

### 方法一：通过 SillyTavern 内置安装器

1. 打开 SillyTavern，进入 **扩展** 页面
2. 点击 **安装插件** 按钮
3. 粘贴仓库地址：`https://github.com/EtafCisky/diary-migration-tool`
4. 等待安装完成

### 方法二：手动安装

1. 下载本工具
2. 将 `diary-migration-tool` 文件夹复制到：
   ```
   SillyTavern/public/scripts/extensions/third-party/
   ```
3. 重启 SillyTavern

---

## 🚀 使用步骤

### 1. 准备工作

- ✅ 确保已安装新版日记本插件（sillytavernDIARY v4.2.0+）
- ✅ 备份 SillyTavern 的 `data/default-user/settings.json` 文件
- ✅ 确保旧版日记数据存在于"日记本"和"回收站"世界书中

### 2. 执行迁移

1. 打开 **扩展设置** 页面
2. 找到 **📦 日记本数据迁移工具** 区域
3. 阅读说明信息
4. 点击 **🚀 开始迁移** 按钮
5. 等待迁移完成（会显示成功提示）

### 3. 验证数据

1. 打开日记本插件
2. 检查日记是否正确迁移
3. 检查回收站是否正确迁移

### 4. 卸载工具

数据迁移成功后，可以安全卸载本工具：

1. 进入 **扩展** 页面
2. 找到 **📦 日记本数据迁移工具**
3. 点击删除按钮

## 📊 数据格式说明

### 旧版格式（世界书）

#### 日记本世界书
- **世界书名称**: "日记本"
- **条目名称**: "标题-时间"
- **关键字**: [作者名]
- **条目内容**: 日记内容

#### 回收站世界书
- **世界书名称**: "回收站"
- **条目名称**: "作者名-回收站"
- **关键字**: [作者名]
- **条目内容**: AI 回复内容

## ⚠️ 注意事项

### 数据安全

- ✅ 迁移过程**不会删除**原世界书数据
- ✅ 如果目标位置已有数据，新数据会**合并**进去
- ✅ 建议在迁移前**备份** settings.json 文件

### 迁移规则

- 📝 日记按作者名分组
- 📝 每个作者的日记按 ID 自动编号（从 1 开始）
- 📝 回收站条目同样按作者名分组和编号
- 📝 如果解析失败，会在控制台输出详细日志

### 常见问题

**Q: 迁移后原世界书数据会被删除吗？**  
A: 不会。迁移工具只读取数据，不会修改或删除原世界书。

**Q: 可以重复执行迁移吗？**  
A: 可以，但会导致数据重复。建议只执行一次。

**Q: 迁移失败怎么办？**  
A: 查看浏览器控制台（F12）的错误信息，或联系作者。

**Q: 迁移完成后需要做什么？**  
A: 验证数据正确后，可以卸载本工具。原世界书可以保留或删除。

## 🔧 技术细节

### 迁移流程

1. **读取世界书** - 使用 `loadWorldInfo()` API
2. **解析条目** - 提取作者名、标题、时间、内容
3. **转换格式** - 转换为新版数据结构
4. **合并数据** - 与现有数据合并（如果有）
5. **保存设置** - 写入 `extension_settings`
6. **显示结果** - 统计并提示用户

### 错误处理

- 条目格式不正确 → 跳过并记录
- 数据不完整 → 跳过并记录
- 世界书不存在 → 提示用户
- 保存失败 → 显示错误信息
